接入文档

5 分钟完成对接。当前为沙盒（Mock）环境，下单不产生真实扣款，但会真实扣减您的门户余额用于验证。

1. 快速开始

  1. 在「API 凭证」页拿到 API Key 与 Secret（丢失可重置）。
  2. 按下方签名规则构造请求头：X-Api-Key、X-Timestamp（当前 Unix 秒）、X-Signature。
  3. 调用 GET /api/open/v1/catalog 查看可售商品与当前报价。
  4. 调用 POST /api/open/v1/quote 获取报价（60 秒锁价）。
  5. 调用 POST /api/open/v1/orders 下单，响应里直接返回卡密。

2. 接口列表

2.1 查询目录 GET /api/open/v1/catalog

无需业务参数。响应：

{ "success": true, "data": [ { "sku": "xplan_1", "name": "ChatGPT Plus 一个月", "currency": "USD", "deliver": "card", "available": true, "price": 11.5 } ] }

2.2 报价 POST /api/open/v1/quote

请求：{ "sku": "xplan_1", "qty": 1 }

{ "success": true, "data": { "quote_id": "q_3c840052dfbc6c11", "unit_price": 11.5, "total": 11.5, "currency": "USD", "cost_basis": 10.0, "expires_in": 60, "expires_at": "2026-10-13T01:40:26Z" } }

2.3 下单 POST /api/open/v1/orders

请求：{ "quote_id": "q_xxx", "client_order_no": "PO-2026-0001" }（client_order_no 是您的单号，≤64 字符，用于幂等）

{ "success": true, "data": { "order_id": "api_mv60jg4o_a5246a", "status": "delivered", "amount": 12.65, "currency": "USD", "cdk": "KC-XXXXXXXXXXXX" } }

2.4 查单 GET /api/open/v1/orders/{order_id}

响应含 status（delivered/failed）与 cdk（卡密）。

3. 签名详解

待签名串（四行，用真实换行拼接）：

POST /api/open/v1/orders 1712345678 e3b0c44298fc1c149afbf4c8996fb92427ae41e4649b934ca495991b7852b855

其中第四行是请求体的 SHA-256（GET 无 body 时对空串求值）；signature = HMAC-SHA256(secret, 上述四行) 的 hex 小写。

Node.js 示例

const crypto = require('crypto'); function sign(secret, method, path, ts, body) { const bodyHash = crypto.createHash('sha256').update(body || '').digest('hex'); return crypto.createHmac('sha256', secret) .update(method + '\n' + path + '\n' + ts + '\n' + bodyHash).digest('hex'); } const body = JSON.stringify({ sku: 'xplan_1', qty: 1 }); const ts = Math.floor(Date.now() / 1000); const headers = { 'Content-Type': 'application/json', 'X-Api-Key': API_KEY, 'X-Timestamp': String(ts), 'X-Signature': sign(API_SECRET, 'POST', '/api/open/v1/quote', ts, body) }; const res = await fetch(BASE + '/api/open/v1/quote', { method: 'POST', headers, body });

Python 示例

import hashlib, hmac, json, time, requests def sign(secret, method, path, ts, body): body_hash = hashlib.sha256((body or '').encode()).hexdigest() canonical = f"{method}\n{path}\n{ts}\n{body_hash}" return hmac.new(secret.encode(), canonical.encode(), hashlib.sha256).hexdigest() body = json.dumps({"sku": "xplan_1", "qty": 1}) ts = int(time.time()) headers = { "Content-Type": "application/json", "X-Api-Key": API_KEY, "X-Timestamp": str(ts), "X-Signature": sign(API_SECRET, "POST", "/api/open/v1/quote", ts, body), } r = requests.post(BASE + "/api/open/v1/quote", headers=headers, data=body, timeout=10)

4. 错误码

codeHTTP含义与处理
INVALID_SIGNATURE401签名失败：检查 secret、待签名串拼接、body 序列化是否一致
TIMESTAMP_EXPIRED401时间戳超出 ±5 分钟：校准服务器时间
INVALID_KEY / CLIENT_DISABLED401/403Key 无效或账户被停用：联系运营
RATE_LIMITED429超过限流（默认 120 次/分钟）：退避重试
SKU_NOT_FOUND / SKU_UNAVAILABLE404/409商品不存在或未开放分销：换 sku 或联系运营
QUOTE_NOT_FOUND / QUOTE_EXPIRED / QUOTE_CONSUMED404/409报价无效/过期/已用：重新 quote
PRICE_CHANGED409报价后成本变动超 3%：按响应里的 new_unit_price 重新报价后再下单
INSUFFICIENT_BALANCE402余额不足：联系运营充值
FULFILL_FAILED502履约失败（余额已自动退回）：重试或联系运营

5. 规则说明

  • 锁价：报价 60 秒内有效；超时请重新报价。
  • 价格保护：报价后上游成本变动超过 3%，下单会返回 PRICE_CHANGED，请按新价重新报价（避免您在成本突变时按旧价成交）。
  • 幂等：client_order_no 全局唯一；重复提交同一单号返回原订单，不会重复扣费。
  • 限流：默认 120 次/分钟，超限返回 429。
  • 交付：下单成功后响应内直接返回卡密；也可随时查单补取。
当前为沙盒（Mock）环境：卡密为测试串，不产生真实上游扣款；正式环境切换前会另行通知。
