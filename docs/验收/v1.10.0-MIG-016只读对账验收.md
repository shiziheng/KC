## 只读边界与匹配规则

- 对账查询执行 `START TRANSACTION READ ONLY`，结束时回滚；不写对账运行记录，不修改 Xboard 或业务库。
- 订单仅按 Xboard `trade_no` 与新业务 `external_order_ref` 完全匹配；重复引用归类为不明确，USDT 不换算为 USD。
- 余额只比较有唯一 Xboard 用户映射和唯一 USD 钱包的账号；缺失/重复映射分别统计，不把缺失余额当作 0。
- CSV 仅含日期、汇总数量和汇总金额，不含邮箱、用户编号或订单明细。
- 查询上限为 31 天；旧 Xboard 订单总量是背景信息，不匹配不直接代表丢单。

实际 MySQL 表结构上的只读查询已成功执行。工具输出只包含成功标志、只读标志和日期范围；没有将用户、订单或余额明细打印到终端或文档。
