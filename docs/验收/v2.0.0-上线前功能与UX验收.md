## 四、发现并修复的缺陷

本轮自动化暴露出 2 个真实产品缺陷（均在后台商品维护链路上），已修复并回归全绿：

| 编号 | 现象 | 根因 | 修复 |
|---|---|---|---|
| D1 | 新建一次性商品报错 `Data truncated for column 'period'`（F2.1 FAIL） | `kc_pricing_rules.period` 的 ENUM 单次值为 `once`，代码写入 `onetime` | `server.js` 商品保存处改写入 `once` |
| D2 | 商品卡片保存报「SKU 不存在」（F3.1 FAIL） | `kc_listing_cards.plan_id` 语义 = `kc_plans.id`，商品保存处误用 `v2_plan.id` 更新卡片，静默失效 | `server.js` 先解析 `kc_plans.id`（`code='xplan_<id>'`）再更新 listing_cards，并提升 `kcPlanId` 作用域 |

修复后重跑：功能 50/50 PASS。其余用例一次通过，无新增缺陷。
