# 第一部分 · 品牌命名

## 一、命名约束（从定位倒推）

| 约束 | 来源 | 说明 |
|---|---|---|
| **要像"上游"** | 客户是小代理 | 名字要让代理觉得"这是我的供货方"，而不是"另一个零售站" |
| **不能有机场联想** | 机场痕迹清理 | 避开：加速、节点、流量、线路、云、极速、飞 |
| **可扩品类** | 未来卖无套餐账号等 | 不能把 GPT/ChatGPT 写进名字（否则卖别的东西时名字就错了） |
| **中文优先** | 客户是中文小代理 | 行话比洋气重要 |
| **2–3 字** | Logo 与口播 | 手机窄屏要放得下，代理之间口口相传要顺 |

> 当前名 **「KC 加速」违反所有 5 条** —— 尤其"加速"是机场专属词，且"KC 加速"完全没有上游感。

## 二、三个候选

### 🥇 主推：**KC 直供**

| | |
|---|---|
| **含义** | 源头直供，没有中间商 |
| **为什么最合适** | ① 一句话说清代理最关心的事（**他是从我这儿直接拿到的，没有二道贩子**）② 天然 B2B 气质，像上游 ③ 不含品类词，卖什么都能用 ④ 与定位句「一个人也算批发」互为表里 |
| **读感** | KC 直供 —— 两字一顿，简洁有力 |
| **风险** | "直供"是常见词，辨识度一般；建议**尽快注册域名与商标** |
| **Logo 建议** | `KC` 方块 + `直供` 两字，或 `KC 直供` 一行 |

### 🥈 备选一：**KC 货仓**

| | |
|---|---|
| **含义** | 有货、有库存的地方 |
| **优势** | **实体感最强** —— 代理最怕"皮包公司跑路"，"货仓"潜台词是"我有货，我跑不了" |
| **劣势** | 略土；可能被理解为仓储/物流服务 |
| **适合** | 如果目标客户更偏低线市场、更看重"实在" |

### 🥉 备选二：**KC 代发**

| | |
|---|---|
| **含义** | 一件代发 —— 中国电商的成熟行话，代理**秒懂** |
| **优势** | 精准命中代理心智："你卖，我发，你不用囤货"；同时暗合"一个人也能做" |
| **劣势** | 容易被误解为物流代发（我们发的是卡密不是实物） |
| **适合** | 如果主攻电商/微商背景的代理 |

## 三、推荐结论

> **用「KC 直供」。**

理由排序：**① 上游感最强**（这是命门）→ ② 无品类绑定（可扩品类）→ ③ 与"批发"定位同频。

## 四、完整使用规范（定名后全站统一）

| 场景 | 用法 |
|---|---|
| 品牌名 | **KC 直供** |
| 正式全称 | KC 直供 · GPT 代充批发 |
| Logo 旁副标 | GPT 代充 · 批发价 |
| 宣传定位句（不变） | **一个人也算批发** |
| 浏览器标题格式 | `{页面名} | KC 直供` |
| 页脚署名 | KC 直供 · 官方渠道代充 · 订单记录可在「我的订单」随时查询 |
| **禁止** | "KC 加速"、"加速"单用、任何机场联想词 |

## 五、改名要动的地方（清单）

`app_name` 一改，**每个页面的浏览器标题都会变**，但页面内还有 5 处硬编码的品牌名必须同步：

| # | 位置 | 来源 |
|---|---|---|
| 1 | **全局站点名** `v2_settings.app_name` | 影响所有页面标题 + 分享预览 |
| 2 | 顶栏 Logo 文字 | `kc_theme_inject.html` |
| 3 | 移动端抽屉头部 | 同上 |
| 4 | 登录用户门户页脚 | 同上 |
| 5 | 游客落地页品牌 | 同上 |
| 6 | 游客门户页脚 + 一处「Xboard → 品牌名」运行时替换规则 | 同上 |

> ⚠️ 第 1 项是**全局生效**的，改完必须 `php artisan optimize:clear`，否则前台仍显示旧名（同 custom_html 的坑）。

# 第二部分 · 定价依据

> 你问的是"为什么会是 15 / 99 / 399，有没有参考"。**有，而且这三个数字的支撑强度不一样** —— 下面逐个说清，并指出最需要验证的是哪一个。

## 六、先看一个更根本的参照：会员费模式本身

**Costco / 山姆会员店的模式，和你说的"权益包"是同一个物种** —— 用低价商品吸引人，用会员费赚钱。

| 数据 | 数值 | 来源 |
|---|---|---|
| Costco 商品毛利率 | **约 13%**（常规零售 30–40%） | 2025 财年 |
| Costco 会员费收入 | **$53 亿** | 2025 财年 |
| **会员费贡献的净利润占比** | **约 2/3**（另有口径 60–75%） | Costco 财报 |
| Costco 会员费 | $65 / $130 年（约 $5.4 / $10.8 每月） | 2024 调价后 |
| 续费率 | 90%+（北美 92.2%） | 2025 |
| 山姆中国会员费 | ¥260 / ¥680 年 | 现行 |
| **山姆约 90% 经营利润来自会员费** | — | 行业调研 |

**关键结论**（可直接用作你商业模式的背书）：

> **商品便宜是手段，不是目的。** Costco 把商品毛利压到 13%，靠会员费赚利润 —— 这证明"**用批发价获客、用会员费赚钱**"是被验证过的大生意模式，不是你的原创冒险。

**一个有意思的验证**：Costco 的「会员费 ÷ 会员年均消费」= **1.9%**，这个比例被认为是"客户感觉划算"的甜点区。

拿你的定价算同一个指标（按中间商品 Pro 100 客单 $93 计）：

| 你的包 | 包费 | 可用次数 × 客单 = 可拿货总额 | 比例 |
|---|---|---|---|
| 轻享包 $15 | $15 | 5 × $93 = $465 | **3.2%** |
| 畅享包 $99 | $99 | 50 × $93 = $4,650 | **2.1%** |
| 畅享包（买 Pro 200 时） | $99 | 50 × $145 = $7,250 | **1.4%** |

> **畅享包落在 1.4%–2.1%，与 Costco 的 1.9% 几乎重合** —— 这是一个很强的信号：定价落在"用户算完觉得划算"的区间里。轻享包的 3.2% 偏高，但它的定位是"验证市场的入场券"，不是"省钱工具"，溢价合理。

## 七、$15 —— 脚踩在 SaaS 入门档的锚点上

### 参考数据

| 参考 | 数值 | 出处 |
|---|---|---|
| **SaaS 入门付费档中位数** | **$19 / 月**（四分位区间 $10–$50） | Toolradar《SaaS Price Points Report 2026》 |
| 该区间的设计逻辑 | "**低到能绕过个人报销审批门槛**，可以不开会就买" | 同上 |
| 常见入门锚点 | $10 / $15 / $19 | 同上 |

### 判断

**$15 完全踩在这个锚点上，合理。** 两个层面的支撑：

1. **决策门槛**：$15 落在 $10–$25 这个"个人可自主决定"的区间。对小代理来说，这个决定不需要跟任何人商量 —— 这正是"**验证市场**"该有的成本。
2. **心理账户**：$15 ≈ 一顿外卖。人不会为"一顿外卖"纠结三天，但会为一个"押 $3,000"的决定纠结三个月。**这是你与行业门槛的核心差异**。

### ⚠️ 一个提醒

$15/月 = **$180/年**。作为参照，国内分销/开店平台的年费是：

| 平台 | 年费 |
|---|---|
| 微店（供货系统） | ¥3,600 / 年（≈$500） |
| 微店（供应商年费） | ¥688 / 年（≈$95） |
| 有赞 | ¥6,800 / 年（≈$944） |
| 金数据小金商户 | ¥599 / 年（≈$83） |

**你的 $180/年 落在这些平台的中间偏下位置**，所以**不算贵**。但要注意区别：**那些平台收的是"工具费"，不参与交易；你收的是"低价拿货的资格费"，同时还在商品上让利 $5–$10/单**。所以不能简单对标，你的价值密度更高。

## 八、$99 —— Charm Pricing 最经典的点位

### 参考数据

| 参考 | 数值 |
|---|---|
| SaaS 价格以 9 结尾的比例 | **29%（最高频）**，整数 0 结尾 27%，5 结尾 18% |
| 认知机制 | **左位数效应**：$99 被感知为"90 多"，而不是"接近 100" |
| 门槛效应 | **$99 不跨三位数**，$100 跨了 —— 心理上是两个不同的价格带 |
| 实测效果 | Buffer 从整数价改 9 结尾 → **转化率 +3.5%**；部分研究报告最高 +24% |
| 经典研究 | $39 有时比 $34 卖得更好（Schindler & Kirby, 1997） |

### 判断

**$99 是三个数字里最"标准答案"的一个。** 它同时命中了：
- **跨过 $100 心理门槛**（左位数效应）
- **三档结构的中间档**（$15 / $99 / $399 是经典入门/主力/专业三档）
- **量价关系合理**：$15/5次 = $3.00/次 → $99/50次 = **$1.98/次，降幅 34%** —— 买越多越便宜，但降幅不足以让轻享包显得亏

### 补充建议：考虑**年付选项**

Costco / 山姆都是**年费制**，年费的商业价值在"锁定 12 个月 + 现金流前置 + 显著降低流失"。

建议增加：**$15/月 或 $150/年**（省 2 个月）、**$99/月 或 $990/年**（省 2 个月）。
- 对代理：年付是"我确定要做这门生意"的信号，给他一个便宜入手的方式
- 对你：现金流前置 + 续费率提升

## 九、$399 —— 三个数字里**最需要验证**的一个

### 参考数据

| 参考 | 说明 |
|---|---|
| B2B 高价区间的定价习惯 | **$500 / $1,000 这类整数更常见** —— 一是采购用表格分析、左位数效应失效，二是整数显得"专业、透明、不像话术" |
| Charm pricing 在 B2B 的效果 | **明显减弱**（"当买方是有经验的采购，左位数锚定效应会缩小"） |
| 但有例外 | 非整数也传递"**经过计算、精确**"的信号；Basecamp 用 $99 正是为了简单透明 |
| 对比你的目标客户 | 小代理 **不是采购部门**，他是价格敏感型的个体户 → **charm pricing 对他仍然有效** |

### 判断

**$399 在"客户感知"层面没问题**（你的客户不是采购，左位数效应对他有效：$399 读作"300 多"）。但它在"**参照系**"层面**缺乏同类锚点**：

- 国内建站/托管服务没有透明公开的标准价（多为 ¥2,000–¥10,000/年 的散乱报价）
- 有赞 ¥6,800/年 ≈ $944/年 ≈ **$79/月**，微店 ¥3,600/年 ≈ **$42/月** —— 你的 $399/月 **显著高于**这两者

**为什么可能仍合理**：那两家卖的是"自助工具"，你卖的是"**API + 帮你建站 + 日常维护**"，含人工服务。含人力的服务，价格天然高出工具一个量级。

**但这意味着两件事必须做到**：

1. **必须把"含什么人工服务"写清楚**（含几次建站对接？维护响应时效？），否则代理会拿它和 ¥688/年 的工具费比较，然后觉得你贵 40 倍。
2. **建议先当试点价**，而不是一次定死。$399 目前**没有市场数据支撑**，是三个数字里唯一"凭感觉"的。可以先小范围试，观察成交率与流失率再调。

## 十、三个数字的支撑强度（一句话总结）

| 数字 | 支撑强度 | 依据 |
|---|---|---|
| **$99** | 🟢 **最强** | Charm pricing 最经典点位 + 入场档锚点延伸 + 与 Costco 费率结构重合 |
| **$15** | 🟢 **强** | 落在 SaaS 入门档 $10–$25"不需审批"区间 + 一顿外卖的心理账户 |
| **$399** | 🟡 **中** | 客户感知没问题（非采购、charm 有效），但**缺同类参照，建议试点验证** |

## 十一、定价部分的三条建议

1. **$15 与 $99 可以直接用**，有充分的外部参照。
2. **$399 建议试点**，并把"含什么人工服务"写细 —— 这是它能否成立的关键。
3. **增加年付选项**（$150/年、$990/年）—— 会员制生意的标准配置，Costco/山姆都是年费制，年付能显著降流失。
