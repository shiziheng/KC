> 前序版本：`v2.0.0`（权益包模式首次成型 —— 机制、组件、经济账仍然有效，**但转化顺序错了**）

## 一、本版修正了什么（只有一件事，但它是根子上的）

### 你的原话

> 「先用权益价吸引人，购买代充服务的代理往往是对价格最敏感的，他们是专家，价格便宜不便宜一眼就知道。再用权益包价格做解释，解释这种权益包适合代理快速验证市场，不要像卡网一样充值数千甚至数万美元才能拿到权益。」

### v2.0.0 错在哪

v2.0.0 的首页第一句话是 **「花 $15，买 5 次低价拿货权」** —— 我**从机制讲起**。

问题在于：**代理还没看到价格，凭什么关心你的机制？** 他对"5 次权益"没有任何概念，也不会因为"$15"这个数字心动（$15 本身不便宜，$15 买到的东西才便宜）。结果就是我把最有杀伤力的东西（**便宜的价格**）藏在了机制说明后面。

### 正确的顺序（三拍）

```
第一拍 · 给价格    →  Pro 200 $145（市场 $180+）
                      代理一眼就知道这是便宜价，因为他天天在看
第二拍 · 给对比    →  拿这个价要什么门槛？$15 起
                      而不是行业常见的"先充几千美元"
第三拍 · 给机制    →  为什么能这么便宜？因为权益包 —— 买次数，不是压资金
                      到这里他才需要"理解"，而理解是为了确认，不是被说服
```

**一句话总结这个修正**：**对专家不要讲道理，先给他数字；他看懂了，自然会问你为什么。**

## 二、第二拍里的杀手级卖点：门槛对比

这是你这次指出的、v2.0.0 完全没表达出来的东西 —— **它可能比"便宜"本身更有说服力**。

### 为什么它这么有力

代理最怕的不是"贵"，是**不确定**：
- 押 $3,000 给平台，平台跑路怎么办
- 押了钱卖不动，钱就死在账上
- 想试水，但试水成本太高，于是干脆不试

你的模式刚好把这三个痛点全解了。所以对比要摆在**价格之后的第二屏**，正对着他刚被价格勾起的那句疑问 ——「要我压多少钱？」

### 对比结构（Demo 采用，措辞已做合规处理）

|  | 行业常见做法 | **我们** |
|---|---|---|
| 拿货门槛 | 先充值数千美元起 | **$15 / 月** |
| 资金占用 | 长期压在平台账上 | **随时可停，不用就退场** |
| 试错成本 | 押错平台 = 全亏 | **$15 试 5 单，跑通再说** |
| 权益方式 | 押金换折扣 | **买次数，用完再续** |

⚠️ **合规提醒（重要）**：对外页面**不要点名具体同行或用贬损性称呼**，也不要写死某个同行的具体充值数字。用「行业常见做法」「传统批发模式」这类中性表述 + 量级词（"数千美元"）即可。
> 理由：点名对比存在不正当竞争风险，且一旦对方改价，你的页面就变成不实陈述。**陈述事实量级 + 让用户自己对号入座**，效果一样好，风险为零。

## 三、首页新结构（v2.1.0）

```
① Hero —— 价格前置（第一拍）
   H1：「Pro 200 $145」
   副标：「市场行情 $180+ ｜ Plus $16.50 ｜ Pro 100 $93」
   条件小字：「$15 权益包解锁 5 次低价拿货机会」
   CTA：查看权益价 / 已有权益？登录
   右侧：三商品价格对照卡（原价 → 权益价）+ 解锁按钮

② 门槛对比（第二拍）★ 本版新增，位置极重要
   「验证市场，不该先押上几千美元」
   左右对照卡：行业常见做法 vs 我们

③ 权益包机制（第三拍）
   现在才解释：权益包 = 买 N 次低价机会，用完恢复原价
   强调：$15 是给"还没验证市场"的人；$99 是给"已验证、要放量"的人

④ 商品双价卡（含三状态切换逻辑，见 v2.0.0 §5.2）

⑤ 步骤 / 代理 / 信任条（沿用 v2.0.0）
```

### Hero 的三个细节要求

1. **价格必须是页面上字号最大的元素** —— H1 就是价格本身（`Pro 200 $145`），不是形容词。
2. **对照物必须在场** —— 光写 $145 不够，要写「市场行情 $180+」。**没有参照系，便宜就不成立。**
3. **解锁条件要小但清晰** —— 放副标下方小字，**不能不写**（否则下单时发现要买包，是欺骗感）；但**不能大**（大了就变成机制先行）。

> 这三条的平衡点：**让用户用 3 秒看到"这里便宜"，再用 5 秒知道"为什么便宜 / 要什么条件"。**

## 四、第三拍：把权益包讲成「验证市场的工具」

v2.0.0 把权益包讲成"省钱工具"，v2.1.0 改成**"低成本验证市场"** —— 因为这是你的原意，而且对目标人群更贴。

### 两种人，两个包

| 他是谁 | 他的处境 | 该买 | 页面上怎么对他说 |
|---|---|---|---|
| **还没验证市场** | 有客户群，不确定卖不卖得动 | **轻享包 $15 / 5 次** | "一顿饭钱，试 5 单就知道。跑不通就停，亏 $15。" |
| **已经稳定出货** | 每月稳定几十单 | **畅享包 $99 / 50 次** | "每次机会成本从 $3.00 降到 $1.98，放量摊薄。" |

> 这个划分还顺手解决了 v2.0.0 遗留的**Plus 亏本问题**：轻享包定位成"试水包"，用户天然会拿它试最贵的商品（利润最高的 Pro 系列）；而 Plus 的折扣薄，本就不适合消耗权益。**如果 Plus 权益价不调整，页面上就应加一句引导**："权益建议用在 Pro 系列，性价比最高"。如果按 v2.0.0 §2 的推荐下调 Plus 权益价，这句引导就不需要了。

### 正式宣传口径建议

> 「**$15 验证市场，不用先压几千美元。**」
>
> 这句可以直接当主标语 —— 它同时命中了"便宜"和"低门槛"两件事，而且是对代理说的行话。

## 五、v2.0.0 里保留不变的部分

以下内容经过本版复核，**仍然有效**，不重复展开：

- **§1 模型定义**：权益包 = 预购折扣次数（买 N 次低价权、每次消耗 1 次、用完恢复原价）
- **§2 经济账与 Plus 亏本问题**（轻享包每次成本 $3.00 / 畅享包 $1.98；Plus 省 $1.50 → 亏）
- **§3 命名红线**：禁止"会员/等级/升级/VIP"；统一句式「用 1 次权益，省 $10」
- **§5 四个核心组件**：次数点阵 ●●○○○ / 双价商品卡（三状态）/ 收益计算器 / 三档对比
- **§7 三个边界情况**：次数是否结转 / 退款是否返次 / 次数用尽时的补包提示
- **§9 分期**：R1 纯前端可立刻做 → R2 权益包后端 → R3 权益包页 → R4 代理页
