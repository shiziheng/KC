## 二、老字段清单（拟下掉 vs 必保留）

### 2.1 拟下掉（迁移完成后可移除）

| 老字段（xboard.v2_plan） | 新表/字段 | 拟下掉版本 | 风险 |
|---|---|---|---|
| `v2_plan.prices` (JSON: {monthly,onetime,…}) | `kc_pricing_rules[period, amount_cents]` | v1.22.0+ | 中（Xboard 原生 `month_price/quarter_price/...` 列冗余但仍被插件读） |
| `v2_plan.kc_card` (JSON) | `kc_listing_cards[card_json]` | v1.22.0+ | 中（插件 PlanCardController 兜底读 `v2_plan.kc_card`） |
| `v2_plan.kc_is_topup` | `kc_plans.kc_type` | v1.22.0+ | 低（仅 0/1 二值） |
| `v2_plan.kc_topup_amount` | `kc_pricing_rules[period='once'].amount_cents` | v1.22.0+ | 低（仅充值型用） |

### 2.2 必须保留（Xboard 原生逻辑依赖）

| 老字段 | 保留原因 |
|---|---|
| `v2_plan.name / transfer_enable / speed_limit / show / sell / sort / reset_traffic` | Xboard 原生订阅/计费逻辑仍直接读；插件与前台暂未改读法 |
| `v2_plan.month_price / quarter_price / half_year_price / year_price / two_year_price / three_year_price` | Xboard 原生订单页与历史订单快照读；冗余但影响兼容性 |
| `v2_plan.content` 等自定义字段 | 暂不在 KC 视图范围内 |
| `v2_plugin.config.packages`（Xboard 插件） | 插件**主路径**仍用 `config.packages` 解析 plan；R3 终极方案改读 KC 侧 BFF 之前不能动 |
| `v2_plugin_kc_cards.cdk_code / status / kc_status` | 履约链路核心表，KC 与 Xboard 共用；R1–R6 未涉及此表 |

## 三、数据一致性实测（2026-10-11）

`node tools/check-legacy-readiness.js` 输出（详见 `logs/legacy-readiness.json`）：

```
legacy v2_plan count: 10
kc_plans count:      10
summary:             { matches: 10, mismatches: 0, kc_only: 0, legacy_only: 0 }
ready_to_drop_legacy: true
```

### 3.1 比对项

| 老字段 | 新字段 | 比对规则 |
|---|---|---|
| `v2_plan.prices.monthly` (USD ×100) | `kc_pricing_rules.period='month'.amount_cents` | cents 相等 |
| `v2_plan.prices.onetime` | `kc_pricing_rules.period='once'.amount_cents` | cents 相等 |
| `v2_plan.prices.quarterly/yearly` | `kc_pricing_rules.period='quarter/year'` | cents 相等（如有） |
| `v2_plan.kc_is_topup` | `kc_plans.kc_type='recharge'` | is_topup=1 → kc_type='recharge' |
| `v2_plan.kc_card` (JSON 非空) | `kc_listing_cards.plan_id=kc.id` | 存在 |
| `v2_plan.kc_card.state` | `kc_listing_cards.listing_state` | 字符串等价 |

### 3.2 period 映射

| v2_plan.prices 键 | kc_pricing_rules.period 值 |
|---|---|
| monthly | month |
| onetime | once |
| quarterly | quarter |
| yearly | year |

## 四、下掉前的剩余工作（≥ v1.22.0）

### 4.1 必做（前置）

1. **BFF 代理接入**：插件 `KcIntegration/PlanCardController.php` 改读 KC 的 `/api/admin/listing-cards`（而非 `v2_plan.kc_card`）。
2. **前台商品页切读法**：R3 已新增 `kc_listing_cards` 双轨回填；切读法意味着移除"同步到 v2"兜底（v1.21.0 仍保留）。
3. **客服台只读路径确认**：v1.13.0 客服工作台读 `v2_plan` 仅用于展示，若改读 KC 需要排期。

### 4.2 可选（增强）

1. **v2_plan.prices 字段类型迁移**：从 JSON 拆成 Xboard 原生 `month_price/quarter_price/...` 列（Xboard 自身兼容性决定）。
2. **`kc_card` / `kc_is_topup` / `kc_topup_amount` 字段 DROP**：直接 `ALTER TABLE xboard.v2_plan DROP COLUMN ...`。
3. **`v2_plugin.config.packages` 字段清空**：配合插件改读法。
