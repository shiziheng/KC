## 一、一句话定位

### 主定位

> **ChatGPT 代充批发，一个人也算批发。**
> $15 起拿货价，不用先压几千美元。

### 备选表述（按场景选用）

| 场景 | 表述 |
|---|---|
| 面向小代理（主） | 一个人也算批发 —— $15 开始，拿代充批发价 |
| 面向个人用户 | 比自己买便宜，分钟级到账 |
| 面向博主 | 有流量就能做生意，建站和售后我们兜 |
| 极简版（Logo 旁副标） | GPT 代充 · 批发价 |

### 为什么是"一个人也算批发"

这句话是我们**与整个行业的正面对比**，而且一句话就把三件事说完了：

1. **行业规则**：批发价是给大客户的，你要先压几千美元才配谈价
2. **我们的规则**：一个人也给你批发价，$15 起
3. **隐含承诺**：我们不靠"你押多少钱"筛客户

它比"便宜"更有力 —— 因为**"便宜"是比价，"一个人也算批发"是改规则**。代理会记住后者。

## 二、这门生意的本质

### 我们靠什么赚钱（一句话）

> **不靠信息差，靠规模和服务费。**

- **不靠信息差**：拿货价就写在页面上，谁能拿多少价，规则完全公开。代理是行家，任何藏着掖着的定价都会被他识破，反而不如全透明。
- **靠规模**：我们集中采购把单价压下来，赚的是采购规模与运营效率的差价。
- **靠服务费**：权益包月费（$15 / $99）、建站支持月费（$399）才是我们的**稳定收入**。商品的价差薄，是获客与留存的工具，不是利润中心。

> ⚠️ **这个认知决定了所有文案的调性**：我们卖的是"持续供货的能力"，不是"一单的便宜"。所以页面上要**主动解释机制**（权益包怎么算），而不是遮掩 —— 遮掩会让代理怀疑后面还有更大的坑。

### 为什么是"次数制"而不是"押金制"

| | 行业常见（押金制） | 我们（次数制） |
|---|---|---|
| 你先付 | 数千美元充值 | $15 |
| 钱的去向 | 变成平台账上的余额 | 买 5 次低价机会 |
| 想退出 | 余额退还困难 | 不再续费即可 |
| 卖不动 | 钱死在账上 | 亏 $15 |

**次数制的真正卖点不是"便宜"，是"退出成本几乎为零"。** 这一条要反复讲 —— 代理被押金制伤过，这是他最听得懂的语言。

## 三、三类客户与他们的真实处境

> 我们有三类客户，**他们在同一个页面上都能找到自己**，因为价格对三类人都是好价。这是优势，不是混乱。

### ① 个人用户（自用）

| | |
|---|---|
| **他是谁** | 自己要用 ChatGPT，嫌官方订阅贵、或没有海外支付手段 |
| **他真正的顾虑** | "便宜是不是有问题？会不会用两天就废？" |
| **他买什么** | 原价单件购买，不需要权益包 |
| **对他说的话** | 正品渠道、分钟级到账、开通失败自动退款 |

### ② 小代理（起步期）★ 核心客户

| | |
|---|---|
| **他是谁** | 有个几十到几百人的客户群，会一点技术，正在找货源 |
| **他真正的顾虑** | "押几千给平台，跑路怎么办？卖不动钱就死了" |
| **他买什么** | 轻享包 $15 → 验证市场；跑通后畅享包 $99 |
| **对他说的话** | **$15 验证市场，不用先压几千美元** |
| **怎么打动他** | 给价格（他一眼判断）+ 给对比（门槛）+ 给机制（为什么便宜） |

### ③ 博主 / 流量主（托管型）

| | |
|---|---|
| **他是谁** | 有粉丝和流量，**不懂技术、也不想管售后** |
| **他真正的顾虑** | "我不会搭站，也没精力处理客户投诉" |
| **他买什么** | 建站支持 $399（API + 帮建站 + 日常维护） |
| **对他说的话** | 有流量就能做生意，站点和售后我们兜 |

> **第③类是你之前提到的"帮博主做维护"，我认为它值得成为一个正式客群。** 因为这类人**付费意愿最高、流失率最低**（他不懂技术，换供应商的成本极高），是最健康的收入来源。$399 的定位不是"更贵的权益包"，而是**"你不用懂技术"的托管服务**。

## 四、产品阶梯：四级成长路径

这是整个定位的骨架 —— **每一级都是上一级的自然升级，用户不需要重新理解规则。**

```
第 0 级 · 个人用户
   原价购买（$18 / $98 / $155）
   进入方式：直接下单
        │
        │  "想拿更低价？"  ↓ $15 / 月
        ▼
第 1 级 · 起步代理
   轻享包 $15 · 5 次低价机会
   定位：验证市场。亏了也就 $15
        │
        │  "跑通了想放量？"  ↓ $99 / 月
        ▼
第 2 级 · 稳定代理
   畅享包 $99 · 50 次（每次成本 $3.00 → $1.98）
   定位：稳定供货，摊薄单次成本
        │
        │  "想有个自己的站？"  ↓ $399 / 月
        ▼
第 3 级 · 白标伙伴（代理 / 博主）
   建站支持套餐 $399
   API 全量开放 + 帮建站 + 日常维护
   定位：你只管卖，剩下我们兜
```

**阶梯设计的三个要点**：

1. **第 0 → 1 级的跨越必须极低**（$15）。这是整个漏斗的命门：代理在犹豫要不要开始，$15 让"开始"这件事的成本低到可以忽略。
2. **每一级都有明确的"该升级的信号"**：次数用完 → 该续包或升档；次数不够用 → 上升档；想有自己的品牌 → 建站。
3. **不要跳级推销**。对一个还在第 0 级的人讲 $399 只会吓跑他。**首页只能主推一个跨越**（现在是 $15），其余留给对应页面。

## 五、价值主张：对每一类人说什么

**首页必须让三类人各找到一句话**（但主推第②类）：

| 客户 | 首页上属于他的那句话 | 位置 |
|---|---|---|
| 个人用户 | "市场行情 $180+，这里 $145" | Hero 副标 |
| **起步代理** | **"$15 验证市场，不用先押几千美元"** | **Hero 条件框 + 第二屏** ★主推 |
| 博主 / 放量代理 | "跑通了再放量，想有自己的站我们用 $399 帮你搭" | 第三屏以下 |

### 核心三句话（全站反复使用，不要换说法）

1. **「一个人也算批发」** —— 定位句，用于 Logo 旁、页脚、分享文案
2. **「$15 验证市场，不用先压几千美元」** —— 转化句，用于首页主 CTA 区域
3. **「用 1 次权益，省 $10」** —— 机制句，用于商品卡、订单、下单确认

> 语言纪律：这三句之外的表述可以变，但这三句**一个字都不要改**。品牌感来自重复。

## 六、品牌与语言体系

### 6.1 品牌名（**待你拍板**）

当前 `KC 加速` 是机场时代的遗留，有两个问题：① "加速"暗示机场业务，与代充心智冲突；② 容易触发对"翻墙类服务"的合规联想。

三个候选方向：

| 方向 | 例子 | 气质 | 适合 |
|---|---|---|---|
| **A. 批发感（推荐）** | KC 代充批发 / KC Supply | 直接、专业、B 端感 | 主打小代理 |
| B. 供货后台感 | KC 供货台 | 强调"后台"关系 | 强调长期合作 |
| C. 工具感 | KC GPT | 中性、干净 | 未来扩品类 |

> **我的建议是 A**。因为你的核心客户是代理，他需要一个"听起来像上游"的名字；"KC GPT" 太像终端品牌，反而弱化了"我是你的供货方"这个关系。

### 6.2 必须清除的历史痕迹

定位清晰的第一步是**删掉不属于定位的东西**。当前站点上仍存在：

- 导航里的 **节点 / 流量 / 重置** 等机场业务菜单
- 营销词里的 **"加速"**
- 术语里的 **订阅 / 套餐 / 服务周期**（改为 账号 / 商品 / 有效期）

> **不清理这些，代理会以为这是个机场，从而怀疑两件事**：你的专业性，以及和你合作本身的合规风险。这一条的优先级高于任何视觉改版。

### 6.3 术语表（对外统一，开发时逐字对照）

| 旧（Xboard 原生） | 新（对外） |
|---|---|
| 订阅 / 套餐 / 计划 | **账号 / 商品** |
| 节点 / 流量 / 重置流量 | **删除**（与本业务无关） |
| 服务周期 30 天 | **有效期 30 天** |
| 代充开通 / 兑卡 | **发卡 / 开通** |
| 余额充值 | **账户余额** |
| 会员 / VIP / 等级 | **禁止出现**（权益机制不是等级） |
| 立即订阅 | **立即购买** |

## 七、明确的边界：我们不做什么

**边界是定位的一半。** 以下是建议写进定位、并在运营中严格遵守的：

### 产品与模式

- ❌ **不做押金/大额预充值** —— 这是我们与行业的核心差异，一旦为了现金流破例，定位立即崩塌
- ❌ **不做无限低价** —— 权益次数用完恢复原价；这是能长期供货的前提，也是筛掉薅羊毛的方式
- ❌ **不做机场 / 节点 / 流量业务** —— 历史业务，彻底切割，不再对外出现
- ❌ **不承诺"永久最低价"** —— 上游成本会波动，只承诺"结构上比行业门槛低"

### 客户与合作

- ❌ **不做大企业定制** —— 客单价与我们的服务模型不匹配（我们可以礼貌地把他们转给上游）
- ❌ **不主动触达代理的客户** —— 白标伙伴的客户名单我们不要、不碰、不营销
- ❌ **不追问代理的定价与客户** —— 他卖给谁、卖多少，与我们无关

### 技术

- ❌ **不保存用户的 ChatGPT 授权信息**（Session / Token / 密码 / 卡号）—— 这是红线，也是可以对外讲的信任点
- ❌ **不做需要用户交账号密码的业务** —— 同上

> **值得注意**：最后两条不是"缺陷"，而是**可以主动宣传的优势**。代理帮客户代充时最怕的就是"要不要把客户的账号给上游" —— 我们明确说"不要"，这是很硬的信任状。

## 八、我们对代理的四条承诺（建议公开写在页面上）

1. **你的客户是你的** —— 我们不主动触达、不索取、不营销
2. **价格全透明** —— 你自己的定价我们不过问；我们的零售价也是公开的
3. **不押资金** —— $15 起，不续费即退出，没有余额提现的坑
4. **上游有波动会提前说** —— 不瞒着你把风险变成你的损失

> 这四条是**定位的信用背书**。代理选择上游时最怕的四个坑，逐条堵上，比任何"实力雄厚"的形容词都有用。

## 九、定位中的四个内在张力（请逐条确认）

这些是你现有想法里**还没收口**的地方。不解决，落地时一定会打架。

### 张力 1：次数制 vs 代理要的"稳定拿货价"

代理的生意模型需要**可预测的成本**。次数制意味着价格会波动（次数用完就变原价），这和他的成本核算习惯冲突。

**建议**：把畅享包（$99 / 50 次）重新表述为**"标准供货配置"**而不是"优惠包" —— 让放量代理默认买它，把次数理解为"月费包含的服务量"，而不是"会被用完的优惠券"。对稳定出货的代理，$1.98/次就是他的**长期成本**，是可预测的。

### 张力 2："便宜"的可持续性（上一轮已提，仍未定）

按现有价格：Plus 权益价 $16.50（省 $1.50）< 每次机会成本 $1.98~$3.00 → **用权益买 Plus 是亏的**。

**建议**：Plus 权益价下调至 $15.00 或更低。理由：Plus 是流量款，用户最先接触；在第一个商品上就发现"不划算"，会摧毁他对整套机制的信任。

### 张力 3：个人用户 vs 代理，同一套价格

个人用户看到 $145 觉得便宜；代理看到 $145 算的是"我卖 $180 赚 $35"。**同一数字两种解读 —— 这是优势**。而且个人用户如果买了权益包，他就自动变成了小代理 —— **这是转化路径，不是自相残杀。**

**要守住的只有一条**：绝不针对代理的客户做定向营销（见第八节承诺 1）。

### 张力 4：机场历史包袱

见 6.2。**优先级最高**，因为它是"专业感"与"合规感"的前提。
