## 二、解决方案（决策已拍板）

### 2.1 处置决策总表

| # | 决策项 | **拍板结果** | 理由 |
|---|---|---|---|
| D1 | 替换文案 | 「服务周期：30 天」/「交付方式：卡密自动发放」 | 与事实一致（支付后自动发卡 → 兑换）；周期转为可读时长 |
| D2 | 列表页「周期」列 | 改名映射（列头「服务周期」） | 保留信息维度，避免空列；与详页面口径一致 |
| D3 | 菜单三项 | 全移除（节点/流量/使用文档） | 机场页 + 占位内容，无业务价值 |
| D4 | 直连拦截 | 做：`#/node`、`#/traffic` → `#/dashboard` | 成本约 10 行，堵历史/收藏直达 |
| D5 | v1.14 主题增量连带上线 | **一并上线并验收** | 主题源已含；拆开部署徒增维护债 |
| D6 | CNY 残留 | 运行时「CNY」→「USD」 | 对齐全站 $ 口径；不碰定价层与收银台 |
| D7 | 个人中心两卡 | 「重置订阅信息」「通知」整卡隐藏 | 订阅模型残留，代充无关 |
| D8 | 保留项 | 个人中心/我的邀请/我的工单/兑换卡密/钱包余额/修改密码 | 业务功能，不动 |

### 2.2 技术策略（四层框架 + 三处能力增强）

四层框架沿用 v1.0.0（编译包审计 → 声明式规则表 → 运行时过滤器 → 词典断言回归），按实测新增三处引擎能力：

- **增强 A · 卡片级隐藏**：按卡片标题（`重置订阅信息`/`通知`）匹配 `.n-card` 整卡 `display:none`（不删除 Vue 节点）
- **增强 B · 货币代码替换**：独立文本节点「CNY」→「USD」；并入既有货币守护心跳（1500ms 轮询），订单页/个人中心全兜住
- **增强 C · 路由静默重定向**：`hashchange` 时若进入 `#/node`、`#/traffic` → `location.replace('#/dashboard')`

### 2.3 规则表 v1.1（完整版，实现即用）

```js
var KC_FF_PERIODS = {
  '月付':'30 天', '季付':'90 天', '半年付':'180 天', '年付':'365 天',
  '两年付':'730 天', '三年付':'1095 天', '一次性':'单次'
};
var KC_FF_RULES = {
  rows: [
    { label:'类型/周期', rename:'服务周期', map:KC_FF_PERIODS },
    { label:'产品流量', rename:'交付方式', value:'卡密自动发放' },
    { label:'旧订阅折抵金额', hide:true },
    { label:'折抵', hide:true }
  ],
  cols: [ { label:'周期', rename:'服务周期', map:KC_FF_PERIODS } ],
  nodes: [ { text:'查看使用教程', hide:true } ],          // 菜单三项直接改模板删除，nodes 兜底
  cards: [ { title:'重置订阅信息', hide:true }, { title:'通知', hide:true } ],
  currency: { from:'CNY', to:'USD' },
  routes: { redirect: { '#/node':'#/dashboard', '#/traffic':'#/dashboard' } }
};
```

### 2.4 引擎行为规格（沿用 v1.0.0 §3.3，硬性约束重申）

- 文案精确整段匹配；幂等标记 `data-kc-ff`
- **只隐藏不删除 Vue 节点**（防 patch 报错）；**禁用 characterData 观察器**
- 触发：boot / hashchange / 订单页 800ms×15 轮询 / 全局 1000ms 心跳 / 主内容区 MutationObserver（childList+subtree，防抖 60ms）
- 幂等自愈：Vue 重渲染刷回原文案时自动再改（窗口 <1s；防闪策略 M3 按需）

## 五、风险与回滚

| 风险 | 缓解 |
|---|---|
| Vue 重渲染覆盖替换 | 心跳 + observer 自愈；幂等 |

| 回滚 | 恢复备份 custom_html 即整体回滚（注入层可逆，无数据变更） |
