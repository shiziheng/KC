服务清单的唯一来源是 **`deploy-manifest.json`** —— 新增/删除/改名服务只改这个文件，Windows 与 Linux 两套引擎自动跟随。

| 动作 | Windows | Linux / macOS |
|---|---|---|
| 启动全部 | 双击 `start_20261007.bat` | `./start_20261007.sh` |
| 停止全部 | 双击 `stop_20261007.bat` | `./stop_20261007.sh` |
| 更新部署 | 双击 `deploy_20261007.bat` | `./deploy_20261007.sh` |
| 控制台菜单 | 双击 `console_20261007.bat` | `./console_20261007.sh` |
