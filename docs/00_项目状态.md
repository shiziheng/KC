### 一键启停（跨平台，文件名已改为英文）

服务清单的唯一来源是 **`deploy-manifest.json`** —— 新增/删除/改名服务只改这个文件，Windows 与 Linux 两套引擎自动跟随。

| 动作 | Windows | Linux / macOS |
|---|---|---|
| 启动全部 | 双击 `start_20261007.bat` | `./start_20261007.sh` |
| 停止全部 | 双击 `stop_20261007.bat` | `./stop_20261007.sh` |
| 更新部署 | 双击 `deploy_20261007.bat` | `./deploy_20261007.sh` |
| 控制台菜单 | 双击 `console_20261007.bat` | `./console_20261007.sh` |
| 引擎 | `kc-deploy_20261007.ps1` | `kc-deploy_20261007.sh` |

其他动作：`status`（看状态）、**`verify`（对比实际运行容器 vs 清单期望，检测漂移；`retired:true` 的服务单列「Retired services」区并显示 `[KEPT]`）**、`list`（打印服务清单，不需 Docker）、`inject`（重放 Xboard 前端注入 —— **v2.0.0 起 xboard `retired:true`，start/deploy/verify/open-urls 均排除该服务；如需回滚须先移除 `retired` 并置回 `inject`**）。

> ⚠️ `.bat` 必须 **GBK(936) 编码 + CRLF 换行**，否则 cmd 解析错位（报 `'hell' 不是内部或外部命令`）、中文乱码。
