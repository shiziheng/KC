四、借鉴什么 / 不照搬什么

借鉴（参考站做得好）

  • 双行大标题，第二行用颜色制造层次
  • 首屏只有一个主 CTA（发光卡），不并列抢焦点
  • 信任前置（把「可信」放在价格之前）
  • 卡片用「描边 + 微发光」代替阴影，深色不脏
  • FAQ 手风琴收页，长尾疑问不干扰主路径

不照搬（对我们不成立）

  • 客户 logo 墙（Oracle/Meta…）—— 会被误解为代理关系
  • 「61 万开发者 / 10B 请求」大数字 —— 量级不支持，编数字自伤信任
  • 粒子/地球大背景 —— 移动端耗电，与付款页气质不符（改为极轻径向渐变）
  • 语言/币种切换、Cookie 弹窗 —— 我们没有多币种/多语言，加了是假功能
  • 全站高发光 —— 金额/地址/二维码面板必须低发光高对比

五、口径铁律（本稿严格遵守）

  • 导航恒 5 项：代充 / 成品号 / 建站服务 / 权益包 / 我的订单（首页由 logo 承担，不占导航）
  • 全站 0 个「会员 / 等级 / 升级 / VIP」；统一表述「权益包」
  • 金额一律 $；权益句式统一「用 1 次权益 · 省 $X」
  • 代充 Session 仅存浏览器内存，不落库、不写 localStorage

六、需要你确认的点

  • ① 配色（已定）：默认 「简约白」亮色；配色归白标租户配置，前台顾客不开放配色切换
  • ② 品牌色：方案的强调色随配色方案走；白标租户自定义 primary_color 仍优先覆盖 --brand
  • ③ 信任条：要不要做？若要做，数字必须接真实运营数据（已交付订单/平均开通时长/到账率），否则建议直接不做。
  • ④ 落地范围：先只做首页（低风险可回滚），还是一次性做全套页面？

已定：默认 「简约白」亮色（v1.1 定稿），配色由白标租户配置（后台选定 5 套之一：墨绿 / 深海蓝 / 靛紫 / 暖橘 / 简约白），前台顾客不提供配色切换；租户自定义品牌色优先级最高。A 经典绿 仅留在评审工具条做对比基线。
