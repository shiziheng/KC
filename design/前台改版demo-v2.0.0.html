常见问题
次数用不完，会留到下个月吗？

不会。权益次数按周期刷新，未使用的不结转 —— 这也意味着次数越早用掉越划算。

用权益买的单，退款了次数会还吗？

会返还次数，不退还权益包费用。（规则待最终确认）

次数用完了怎么办？

按原价购买即可，随时可以补权益包或用完再续。

可以把权益用在最贵的商品上吗？

可以，而且建议这么做。系统在设计上会优先把权益用在「每次省得最多」的商品上。

代理

把下单能力接进你的生意

你的客户在你的站点下单，我们自动发货。你只管定价和卖，其他环节都不用碰。

接入 API · 三步

01

拿一个 Key

购买建站支持套餐后，后台自助生成，不用审批。

02

调用下单接口

传商品和你的客户单号，自动消耗权益按权益价扣费。

03

拿到卡密

响应里直接带回卡密，交给你的客户即可。

# 下单并拿卡密（响应对手发给你的客户） curl -X POST https://api.example.com/api/open/v1/orders \ -H "X-Api-Key: sk_live_xxxxxxxx" \ -H "X-Signature: <HMAC-SHA256>" \ -d '{ "sku": "pro200_30d", "client_order_no": "your-order-001", "use_quota": true }' # 返回 { "card_key": "KC-XXXX-XXXX-XXXX", "amount": "145.00", "quota_used": 1, "quota_left": 2 }

响应里直接回传剩余次数，方便你在自己的站点展示。
